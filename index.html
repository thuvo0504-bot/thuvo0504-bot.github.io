2. Delivery Order Delay Risk Prediction & Operational Cost Optimization

Công nghệ: Python, PySpark, MongoDB, Dash Plotly, Open-Meteo API

Mô tả: Xây dựng hệ thống phân tích dữ liệu lớn xử lý hơn 930.000+ bản ghi đơn hàng, tích hợp dữ liệu thời tiết thực tế qua API và lịch nghỉ lễ. Xây dựng mô hình phân loại (Logistic Regression Balanced, AUC = 0.8259) dự báo trễ đơn hàng, giúp tối ưu hóa và tiết kiệm 21.95% chi phí vận hành cho doanh nghiệp.
